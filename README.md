# Komi OS

This is Komi OS, a WebOS created by me that is heavily inspired by Komi Can't Communicate. I've always wanted to make something like an operating system on the web and I got the chance to do that during Hack Club's Stardance event.

### Main features:
- Launchable apps on the desktop and taskbar
- Multiple apps including:
  - Text editor
  - Music player
  - Configurable settings
  - Minecraft
- Infinite number of windows - you can launch as many instances of Minecraft as your computer can handle
- Settings persistence - will remember your wallpaper and won't show you the boot screen every time you reload the page
- Fully Komi-ified!

However a couple other notable features include:
- Boot screen
- Wallpaper switching
- Custom right click menu

## 🚀 How to run it locally

This project runs JavaScript as modules so to run it locally, clone the repo and run index.html in a local dev server (eg using Python or Vite, or what I personally do is use the Live Server extension in VS Code) and you should be good to go.
